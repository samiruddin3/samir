RAWZAH — CARTFLOWS CHECKOUT INSTALLER 2.1

Upload Rawzah-CartFlows-Ready.zip at WordPress > Plugins > Add New > Upload.
If Rawzah is already installed, choose Replace current with uploaded.
This is a WordPress installer for a CartFlows checkout design, not a native
CartFlows Import Flow JSON. All displayed artwork and fonts are included.

1. Activate Elementor, WooCommerce, CartFlows and this installer.
   Pages > Rawzah Elementor > Import Visual Story v2 + All Images if shown.
2. CartFlows > your flow > Checkout step > Products: assign the actual Rawzah
   WooCommerce product (BDT 899, physical, published, in stock).
   Select Classic / One Column checkout and keep a Thank You step in your flow.
3. Pages > Rawzah Elementor > CartFlows Checkout selector:
   choose your checkout and click the Bengali Apply Rawzah design button.
   The old design is backed up as an Elementor template named Before Rawzah …
   Applying to a published step changes its visible design immediately.
4. Enable the optional three-field mobile preset using your actual Product ID.
   Enable WooCommerce guest checkout and COD; keep this installer active if
   using the mobile preset. Delivery: Dhaka 60 / outside 100.
5. Test an order on your live CartFlows checkout URL before ad traffic.

Manual option: Edit the Checkout step with Elementor > Canvas > My Templates >
Rawzah — Visual Story v2 + CartFlows > Insert. One checkout shortcode is included.
Do not add another checkout widget. Products, flow links and payment settings
stay controlled by CartFlows/WooCommerce. This installer only applies the design.

See CARTFLOWS-START-HERE-BN.txt for Bangla instructions and validation limits.
